# Pop اختيار التخصص بنفس Pop روابط القنوات العلمية

تم تعديل اختيار التخصص ليعمل بنفس منطق نافذة "روابط القنوات العلمية":

- نافذة مستقلة فوق الصفحة Backdrop.
- نفس أسلوب bottom sheet.
- لا تنقص عند السكرول.
- لا تتأثر بحدود أو overflow نافذة روابط القنوات.
- عرضها أصغر من نافذة روابط القنوات العلمية.
- تحتوي على handle بالأعلى مثل pop الأصلي.
- التصميم أخف وأنظف ومناسب للألوان.
