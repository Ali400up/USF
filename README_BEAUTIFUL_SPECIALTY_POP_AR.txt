# تحسين شكل Pop اختيار التخصص

تم تحسين نافذة اختيار التخصص في روابط القنوات العلمية:

- خلفية مظللة أوضح حتى لا تختلط النافذة مع الموقع.
- إطار متدرج مناسب لألوان الموقع.
- رأس جميل للنافذة.
- بطاقات التخصصات أصبحت أنظف وأوضح.
- تأثير hover وحركة فتح ناعمة.
- متجاوبة مع الهاتف.
