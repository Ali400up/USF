# تحديث الموقع ولوحة التحكم

## التعديلات الجديدة

1. قسم الشكاوى:
- تمت إضافة خانة رقم الهاتف بجانب الاسم.
- يتم حفظ الرقم في جدول student_issues داخل حقل phone_number.
- تمت إضافة الحقل في لوحة التحكم admin.html.

2. قسم إنجازات الملتقى:
- تم تطوير القسم من أرقام فقط إلى إنجازات تفصيلية.
- كل إنجاز يمكن أن يحتوي على:
  - اسم الإنجاز
  - وصف مختصر
  - تفاصيل
  - تاريخ الإنجاز
  - التصنيف
  - صورة رئيسية
  - صور متعددة للإنجاز أو التكريم
  - أيقونة
  - ترتيب الظهور
- التحكم كامل من admin.html عبر جدول achievements.

3. قسم المبادرة الطلابية:
- تمت إضافة قسم جديد في الصفحة الرئيسية باسم المبادرة الطلابية.
- يمكن عرض مبادرات مثل:
  - مبادرة تبرع أو تبادل الكتب
  - مبادرة خيرية لدعم الطلاب
  - مبادرة تطوعية
  - مقترح مبادرة طلابية
- كل مبادرة يمكن أن تحتوي على:
  - اسم المبادرة
  - وصف مختصر
  - تفاصيل
  - التاريخ
  - التصنيف
  - الحالة
  - الجهة المنفذة
  - الفئة المستهدفة
  - صورة رئيسية
  - صور متعددة
- التحكم كامل من admin.html عبر جدول student_initiatives.

4. حذف قسم معرض مختصر:
- تم حذف القسم القديم الذي يحتوي على:
  - معرض مختصر
  - مساحة مستقبلية لصور وتغطيات الملتقى
  - تغطية الأنشطة
  - برامج تدريبية
  - أرشيف الملتقى

5. الروابط الجديدة:
- /initiatives
- /initiatives/:id
- /achievements
- /achievements/:id

## مهم جدًا قبل النشر

شغّل ملف:
SUPABASE_UPDATE_SCHEMA.sql
داخل Supabase SQL Editor.

ثم ارفع الملفات إلى Vercel واعمل Redeploy.
