# صفحات ID بنفس تصميم الموقع الرئيسي

تم تعديل api/seo-page.js حتى تكون صفحات التفاصيل للمستخدمين بنفس شكل الموقع الرئيسي:

- تستخدم نفس CSS الأصلي.
- تستخدم نفس كروت التفاصيل activity-details-box.
- تستخدم نفس activity-info-card.
- تستخدم نفس activity-details-gallery.
- تستخدم نفس committee-link-card للروابط.
- تعرض الروابط والقنوات للجان.
- تعرض التفاصيل والصور والبيانات بشكل مرتب وجميل للمستخدمين.

بعد الرفع اعمل Redeploy من Vercel.
