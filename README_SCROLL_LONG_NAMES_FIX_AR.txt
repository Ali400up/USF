# إصلاح Scroll والأسماء الطويلة

تم إصلاح مشكلتين:

1. لون Scroll في Chrome:
- تم تخصيص ::-webkit-scrollbar
- أصبح لون السكرول واضحًا ومتوافقًا مع ألوان الموقع

2. الأسماء الطويلة:
- اسم القناة الطويل لا يكسر البطاقة
- اسم الكلية الطويل لا يكسر التصميم
- النص الطويل يظهر بسطرين كحد أقصى
- البطاقات في الهاتف تتحول بشكل مناسب
- الأزرار لا تختلط مع النص
