# تصغير Pop اختيار التخصص

تم تعديل نافذة اختيار التخصص لتكون أصغر من نافذة روابط القنوات العلمية، حتى تظهر بوضوح أنها نافذة فرعية.

تم أيضًا معالجة مشكلة الأسماء الطويلة مثل:
إدارة أعمال دولية+ إدارة أعمال+ تسويق رقمي

التحسينات:
- تصغير عرض النافذة.
- جعل الخيارات قائمة عمودية أنظف.
- منع كسر التصميم مع الأسماء الطويلة.
- إظهار الاسم الطويل في سطرين كحد أقصى مع ترتيب البطاقة.
- المحافظة على ألوان الموقع والإطار المتدرج.
