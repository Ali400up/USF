# تصميم اختيار التخصص من Pop

تم تعديل نافذة روابط القنوات العلمية:

- اختيار التخصص لم يعد صفوف أزرار أو scroll.
- أصبح زر واحد جميل باسم "اختر التخصص".
- عند الضغط عليه تفتح نافذة Pop صغيرة داخل نفس التصميم.
- تظهر التخصصات داخل pop على شكل بطاقات أنيقة.
- عند اختيار تخصص، تُغلق النافذة وتظهر قنوات التخصص فقط.
- التصميم متوافق مع ألوان الموقع.
- الملفات المعدلة:
  index.html
  api/seo-page.js
