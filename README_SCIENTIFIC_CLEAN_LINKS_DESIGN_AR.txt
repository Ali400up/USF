# تحسين تصميم روابط القنوات العلمية

تم تعديل تصميم نافذة "روابط القنوات العلمية" بناءً على الملاحظات:

- إزالة الـ scroll من اختيار التخصصات.
- التخصصات تظهر جنب بعض وتنتقل لسطر جديد تلقائيًا إذا لم تكفِ المساحة.
- إزالة شكل "إطار داخل إطار داخل إطار".
- حذف عناوين مثل: العلوم الإدارية / قنوات ... / عدد القنوات داخل كل كلية.
- عند اختيار تخصص تظهر القنوات مباشرة بشكل بطاقات نظيفة.
- كل بطاقة تعرض:
  اسم القناة
  الكلية
  المستوى
  زر فتح القناة
