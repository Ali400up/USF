# إصلاح جدول المبادرات وإضافة مقترحات المبادرات

## الخطأ الذي ظهر
Could not find the table public.student_initiatives in the schema cache

معناه أن جدول student_initiatives لم يُنشأ في Supabase أو أن PostgREST لم يحدث schema cache بعد.

## الحل
1. افتح Supabase.
2. اذهب إلى SQL Editor.
3. شغّل الملف: RUN_THIS_SQL_FIRST.sql
4. انتظر 30 إلى 60 ثانية.
5. افتح لوحة الأدمن وجرب قسم المبادرات.

## الإضافات الجديدة
- جدول student_initiative_suggestions لاستقبال مقترحات الطلاب.
- نموذج في الصفحة الرئيسية داخل قسم المبادرات بعنوان: اقترح مبادرة طلابية.
- قسم جديد في admin.html باسم: مقترحات المبادرات.
- الطلاب يستطيعون الإرسال فقط، ولا يستطيعون قراءة المقترحات.
- الأدمن يستطيع عرض المقترحات وتعديل حالتها وإضافة ملاحظات.
