# تحديث تصميم صفحات الأقسام

تم تعديل api/section-page.js بحيث تظهر صفحات الأقسام كأنها نفس أقسام الصفحة الرئيسية مقصوصة وحدها:

- /news يظهر بتصميم التلفاز نفسه الموجود في الصفحة الرئيسية.
- /activities يظهر بنفس كروت الأنشطة.
- /courses يظهر بنفس كروت الدورات والفلاتر.
- /committees يظهر بنفس كروت اللجان.
- /achievements يظهر بنفس كروت الإنجازات.
- /events يظهر بنفس الفعاليات القادمة الموجود في الصفحة الرئيسية.
