# إصلاح Scroll نافذة روابط القنوات العلمية

تم إصلاح مشكلة نافذة روابط القنوات العلمية عندما يكون المحتوى أطول من الشاشة.

الآن:
- النافذة لا يخرج محتواها خارج الشاشة.
- رأس النافذة يبقى ثابتًا.
- قائمة الروابط فقط تعمل Scroll داخلي.
- يعمل على الهاتف والكمبيوتر.
- تم الحفاظ على تصميم Pop اختيار التخصص الجديد.
