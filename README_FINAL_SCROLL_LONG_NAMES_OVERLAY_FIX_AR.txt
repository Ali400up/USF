# الإصلاح النهائي للأسماء الطويلة والـ Scroll والطبقة الخفيفة

تم تنفيذ الآتي:

1. إصلاح الاسم الطويل مثل:
إدارة أعمال دولية+ إدارة أعمال+ تسويق رقمي
بحيث لا يخرج من عرض Pop ولا يكسر التصميم.

2. تحسين لون Scroll في Chrome:
- أصبح خافتًا وناعمًا.
- لا يظهر بلون قوي أو مزعج.

3. إزالة الطبقة/اللون الخفيف الذي كان يظهر ويختفي عند السكرول:
- تم تعطيل pseudo overlay القديم.
- تم اعتماد overlay ثابت ونظيف فقط أثناء فتح Pop اختيار التخصص.

4. تحسين Pop اختيار الكلية/التخصص:
- لا يكسر التصميم مع الأسماء الطويلة.
- لا يسمح بخروج النص من العرض الطبيعي.
- يحافظ على نفس منطق Pop روابط القنوات.
