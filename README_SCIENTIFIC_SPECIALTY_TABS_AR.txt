# تحديث عرض قنوات اللجنة العلمية المركزية

تم تعديل الموقع ولوحة التحكم بحيث تظهر روابط القنوات العلمية بشكل أجمل:

## في الموقع

عند الضغط على "روابط القنوات العلمية" تظهر التخصصات في الأعلى على شكل أزرار مرتبة بأيقونات.
وعند الضغط على أي تخصص تظهر قنواته فقط، مرتبة حسب الكلية والمستوى.

مثال:
- أمن سيبراني
- نظم المعلومات
- تقنية المعلومات
- طب الأسنان
- محاسبة
- إدارة أعمال

## في لوحة التحكم

داخل قسم "روابط اللجان" أضيف حقل:

أيقونة التخصص

وتستطيع تحديد أيقونة لكل تخصص مثل:
- fa-solid fa-shield-halved لأمن سيبراني
- fa-solid fa-brain للذكاء الاصطناعي
- fa-solid fa-tooth لطب الأسنان
- fa-solid fa-calculator للمحاسبة

## ملفات SQL

1. إذا تريد فقط إضافة الحقول:
RUN_THIS_FOR_SCIENTIFIC_SPECIALTY_TABS.sql

2. إذا تريد إدخال كل روابط ملف الإكسل مع أيقونة لكل تخصص:
IMPORT_FULL_SCIENTIFIC_COMMITTEE_CHANNELS_WITH_SPECIALTY_ICONS.sql

الأفضل لك الآن:
شغّل ملف الاستيراد الكامل:
IMPORT_FULL_SCIENTIFIC_COMMITTEE_CHANNELS_WITH_SPECIALTY_ICONS.sql

ثم ارفع ملفات الموقع واعمل Redeploy.
