# منع قص Pop اختيار التخصص وتصغيره

تم تعديل نافذة اختيار التخصص:

- منع قص النافذة عند السكرول داخل روابط القنوات العلمية.
- جعلها تظهر كـ Pop حقيقي فوق كل العناصر.
- رفع z-index حتى لا تختلط أو تنقص من الأسفل.
- تصغير العرض أكثر.
- تقليل حجم الخيارات والهوامش مع بقاء الأسماء الطويلة مرتبة.
