# التعديل النهائي لقنوات اللجنة العلمية

تم تنفيذ المطلوب:

1. لم يعد هناك قسم مستقل باسم "جميع المستويات".
2. إذا كانت القناة لجميع المستويات، تظهر داخل قسم الكلية التابعة لها.
   مثال:
   ملتقى اللجان العلمية بالكلية العلوم الإدارية
   سيظهر داخل قسم: العلوم الإدارية
   وليس في قسم منفصل.
3. نافذة اختيار التخصص أصبحت Pop واضحة بظل أقوى وخلفية منفصلة.
4. في admin.html تم تحويل حقل المستوى إلى اختيار مرتب:
   جميع المستويات
   الأول
   الثاني
   الثالث
   الرابع
   الخامس
   السادس
   الامتياز
   عام
