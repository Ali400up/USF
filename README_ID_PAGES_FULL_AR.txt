# تحديث صفحات التفاصيل حسب ID

تم تعديل api/seo-page.js بحيث تعرض صفحات التفاصيل لكل الأقسام بشكل منظم وكامل:

- /news/:id
- /courses/:id
- /activities/:id
- /events/:id
- /committees/:id
- /achievements/:id
- /initiatives/:id

المميزات:
- عرض العنوان والوصف والتفاصيل.
- عرض كل الصور و gallery_images.
- عرض معلومات مختصرة مثل التصنيف والحالة والتاريخ والموقع والمقاعد.
- عرض بيانات إضافية من الحقول الموجودة في قاعدة البيانات.
- عرض روابط الخبر أو الروابط الموجودة داخل النص.
- عرض مهام اللجنة إن وجدت.
- عرض روابط اللجنة والقنوات من جدول committee_links إذا كانت الصفحة لجنة.
- الحفاظ على نفس روح وتصميم الصفحة الرئيسية باستخدام نفس CSS والكلاسات.

بعد الرفع اعمل Redeploy من Vercel.
